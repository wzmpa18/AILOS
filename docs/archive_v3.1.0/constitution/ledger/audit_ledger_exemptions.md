# 架构遗留豁免分册 — P2 终验版（审批流程 + 全部审批记录）

> **账簿版本**: v3.0.0 | **审批规则**: 所有豁免必须总工程师审批，禁止开发自批自免
> **审批流程**: 开发提交豁免申请 → 总工程师审批 → 登记入账 → 标注 Deadline

---

## 审批流程

```
开发提交豁免申请（附理由+文件+违宪编号）
  → 总工程师审批（通过/驳回/要求补充）
    → 通过：登记入账，标注生效期限
    → 驳回：按一级违宪继续整改
```

**禁止规则**：
- 禁止开发自行添加豁免项
- 禁止永久豁免（必须标注失效日期或"架构整改完成后自动失效"）
- 临时豁免最长 30 天，超期自动转为一级违宪

---

## 豁免复核机制（P3 审计新增）

| 规则 | 说明 |
|------|------|
| 核心模型类豁免 | 每 6 个月复核一次（Brain 内核相关） |
| 基础设施类豁免 | 每 12 个月复核一次（支付/风控/短信） |
| 永久豁免 | 必须标注"永久（无风险）"理由，每年审计确认 |
| 复核不通过 | 立即作废豁免，按一级违宪启动整改 |
