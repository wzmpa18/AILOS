# 增补 5：前端全局变量边界规范

> 文档性质：P0 强制增补项，明确 window.AILOS 暴露边界，封死前端绕过权限
> 关联宪法：产品宪法 9.2 三维语言管控、CoreOS 第 0.1 铁律 SSOT

---

## 5.1 window.AILOS 暴露方法白名单

### ✅ 允许暴露（只读 / 无副作用）

| 方法名 | 用途 | 副作用 |
|--------|------|--------|
| `AILOS.getUILang()` | 获取界面语言 | 无 |
| `AILOS.getStudyLang()` | 获取目标学习语言 | 无 |
| `AILOS.getNativeLang()` | 获取母语 | 无 |
| `AILOS.getToken()` | 获取当前登录 token | 无 |
| `AILOS.isLoggedIn()` | 判断是否已登录 | 无 |
| `AILOS.renderNav()` | 渲染底部导航 | 仅 UI |
| `AILOS.playTTS(text, lang, opts)` | 播放 TTS 语音 | 仅语音 |
| `AILOS.NAV_ITEMS` | 底部导航配置（只读） | 无 |
| `AILOS.LANG_NAMES` | 语言名称映射（只读） | 无 |
| `AILOS.CODE_TO_LABEL` | 语言代码映射（只读） | 无 |
| `AILOS.TRADITIONAL_I18N` | 繁体中文翻译表（只读） | 无 |

### ❌ 禁止暴露（必须走后端接口校验）

| 方法名 | 原因 | 替代方案 |
|--------|------|---------|
| `AILOS.setUILang()` | 直接改缓存，绕过 SSOT | 调用 `/api/language` 后端接口 |
| `AILOS.setStudyLang()` | 直接改缓存，绕过 SSOT | 调用 `/api/language` 后端接口 |
| `AILOS.setNativeLang()` | 直接改缓存，绕过 SSOT | 调用 `/api/language` 后端接口 |
| 任何积分操作 | 直接改前端变量 | 调用后端积分接口 |
| 任何配额修改 | 直接改 localStorage | 调用后端配额接口 |

## 5.2 前端数据修改唯一路径

```
用户操作 → 调用后端 API → 后端校验 → 更新 SSOT 主表 → CoreOS 发布事件 → 缓存自动刷新 → 前端重新读取
```

**禁止路径**：
```
❌ 用户操作 → 直接改 localStorage → 前端立即生效（绕过 SSOT）
❌ 用户操作 → 调用 window.AILOS.xxx() → 直接改内存变量（绕过 SSOT）
```

## 5.3 已暴露但应收敛的方法清单

| 方法名 | 当前暴露位置 | 收敛方案 |
|--------|------------|---------|
| `setUILang` | `window.AILOS.setUILang` | P2 改为仅暴露 `requestSetUILang(lang)` → 后端校验 |
| `setStudyLang` | `window.AILOS.setStudyLang` | 同上 |
| `setNativeLang` | `window.AILOS.setNativeLang` | 同上 |
