## 4.5 销号流程（不可跳步）

```
PENDING（待整改）→ IN_PROGRESS（整改中）→ TEST（验收中）→ FROZEN（已销号）
                                                      ↘ REJECTED（驳回重改）
```

**规则**：
- 状态变更必须附操作人 + 时间 + 原因，记录到状态变更日志
- 一级违宪直接 FROZEN 必须附：验收截图 + 代码 diff + CI 扫描报告
- 禁止从 PENDING 直接跳到 FROZEN（跳过 TEST 阶段）
