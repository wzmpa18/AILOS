## 1. 路线概览

### 1.1 产品愿景

AILOS 的终极形态不是一款语言学习 APP，而是一个**AI 原生全层级教育操作系统**。这意味着：

- **横向扩展**: 覆盖学习全生命周期（学 → 练 → 测 → 评 → 教 → 创 → 变现）
- **纵向深化**: 从个人学习者 → 家庭 → 班级 → 学校 → 机构 → 全球教育生态
- **AI 驱动**: 每一层都深度嵌入 AI（混元大模型），而非简单套壳

## 2. 多身份体系

### 2.1 目标

AILOS 不是"一刀切"的通用 APP，而是为每个角色提供**独立空间和专属功能面板**。

### 2.2 五类身份定义

| 身份 | 代码 | 核心需求 | 独立面板 | 目标阶段 |
|------|------|---------|---------|---------|
| **学生** | `student` | 学习外语、提升能力 | 学习面板 + 进度追踪 + AI 语伴 | Milestone 1（已上线） |
| **家长** | `parent` | 监控孩子学习进度、控制使用时长 | 家长面板 + 学习报告 + 时长控制 | Milestone 2 |
| **教师** | `teacher` | 班级管理、作业布置批改、学生数据追踪 | 教师面板 + 班级管理 + 作业系统 | Milestone 2 |
| **机构管理员** | `org_admin` | 多教师管理、批量学生导入、机构级数据报表 | 机构后台 + 成员管理 + 数据报表 | Milestone 2 |
| **内容创作者** | `creator` | 课程发布、社群运营、收益分成 | 创作者面板 + 课程管理 + 收益中心 | Milestone 3 |

### 2.3 当前基础设施

当前 `UserIdentity` 表已支持 `identityType` 字段（`personal` / `teacher` / `school` / `enterprise`），为多身份体系提供了数据基础。Milestone 2 需要在此基础上：

```
当前状态:
  UserIdentity.identityType = ['personal', 'teacher', 'school', 'enterprise']

Milestone 2 扩展:
  UserIdentity.identityType = ['student', 'parent', 'teacher', 'org_admin', 'creator']
  + 新增 UserIdentity.profileData（各身份专属配置 JSON）
  + 新增 UserIdentity.verifiedStatus（身份认证状态）
  + 新增 IdentityPermission（身份权限白名单）
```

### 2.4 各身份独立面板功能

#### 学生面板（当前已上线）

- 个性化学习 Dashboard（7 语种 GLOI）
- 学习能力模型 6 维度可视化
- 学习进度追踪
- AI 语伴对话
- 课程学习

#### 家长面板（Milestone 2）

```
功能清单:
  ├─ 绑定孩子账号（家长-学生关联）
  ├─ 学习进度实时查看
  ├─ 能力评估报告（周报/月报）
  ├─ 使用时长控制（每日上限、禁用时段）
  ├─ 消费记录查询（付费课程购买记录）
  └─ 消息通知（孩子完成课程/获得成就）
```

#### 教师面板（Milestone 2）

```
功能清单:
  ├─ 班级管理（创建班级、邀请学生、分组管理）
  ├─ 作业系统（布置作业、批改、评分、统计）
  ├─ 学生数据追踪（个体/班级维度）
  ├─ AI 辅助备课（混元生成教案/练习题）
  ├─ 课程资源库（共享课件/习题）
  └─ 教学报告（班级学习效果分析）
```

#### 机构后台（Milestone 2）

```
功能清单:
  ├─ 多教师管理（添加/移除/权限分配）
  ├─ 批量学生导入（CSV/Excel）
  ├─ 机构级数据报表（Dashboard）
  ├─ 课程体系管理（机构定制课程）
  ├─ 品牌定制（机构 Logo/名称/主题色）
  └─ 账单管理（机构付费/教师课酬）
```

#### 创作者面板（Milestone 3）

```
功能清单:
  ├─ 课程编辑器（富文本/视频/音频/习题）
  ├─ 课程上架管理（定价/预览/发布）
  ├─ 收益中心（销售数据/提现/账单）
  ├─ 粉丝/学员管理（社群运营）
  ├─ 数据分析（课程销量/学员评价）
  └─ AI 辅助创作（混元生成课程大纲/习题）
```

### 2.5 身份切换机制

用户可拥有多个身份（如：既是学生又是创作者），通过顶部导航栏身份切换器切换面板：

```
用户: 张三
  ├─ 🎓 学生身份 → 学习面板
  ├─ 👨‍🏫 教师身份 → 教师面板
  └─ ✍️ 创作者身份 → 创作者面板（Milestone 3）
```

## 3. 组织生态

### 3.1 目标

构建完整的 **B 端教育机构服务生态**，让学校、培训机构、语言学校能够在 AILOS 平台上管理教学。

### 3.2 当前基础设施

当前已具备 MVP 轻量级组织模型：

```
Organization (机构)
  ├─ id, name, description, logoUrl, status
  └─ members: OrganizationMember[]

OrganizationMember (成员)
  ├─ organizationId, userId, role (admin/teacher/student)
  └─ status (active/suspended/left)

Workspace (工作空间)
  ├─ type: personal | organization
  └─ config: Json (可扩展)
```

### 3.3 Milestone 2 扩展

#### 3.3.1 机构发现与加入

```
用户流程:
  1. 机构检索 → 按名称/地区/语种搜索机构
  2. 机构主页 → 查看机构介绍、教师列表、课程体系
  3. 申请加入 → 填写申请信息（身份/班级/学习目标）
  4. 管理员审核 → 通过/拒绝/要求补充信息
  5. 加入成功 → 自动创建 Workspace(type=organization)
```

#### 3.3.2 班级体系

```
新增数据表: Class (班级)
  ├─ id, name, organizationId, teacherId
  ├─ grade, subject, description
  └─ students: ClassStudent[]

新增数据表: ClassStudent (班级学生)
  ├─ classId, userId, studentNo
  └─ status (active/inactive/graduated)

新增数据表: ClassAssignment (班级作业)
  ├─ id, classId, teacherId
  ├─ title, content, dueDate
  └─ submissions: AssignmentSubmission[]

新增数据表: AssignmentSubmission (作业提交)
  ├─ id, assignmentId, studentId
  ├─ content, attachments, score, feedback
  └─ status (draft/submitted/graded)
```

#### 3.3.3 机构管理功能

```
机构管理员:
  ├─ 成员管理（添加/移除/角色分配）
  ├─ 班级管理（创建/编辑/归档）
  ├─ 教师管理（分配班级/查看教学数据）
  ├─ 学生管理（批量导入/转班/毕业）
  ├─ 数据报表（机构级学习数据看板）
  └─ 机构设置（名称/Logo/简介/联系方式）
```

### 3.4 依赖关系

```
多身份体系 (teacher/org_admin)
  └─→ 组织生态 (Organization + Class + Assignment)
        └─→ 知识付费生态 (机构定制课程 + 教师课酬)
```

## 4. 学习搭子社交

### 4.1 目标

构建**轻量级学习社交网络**，让用户找到学习伙伴，提升学习动力和留存率。

### 4.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **学习优先** | 社交为学习服务，不做泛社交平台 |
| **隐私安全** | 未成年人保护、个人信息脱敏 |
| **AI 推荐** | 混元驱动智能匹配，非随机推荐 |
| **轻量互动** | 专注学习搭子配对，不做朋友圈/动态流 |

### 4.3 功能模块

#### 4.3.1 智能匹配引擎

```
匹配维度（按权重排序）:
  1. 母语相同 (nativeLanguage) —— 权重 35%
  2. 目标语言相同 (targetLanguage) —— 权重 30%
  3. 水平相近 (level) —— 权重 20%
  4. 学习目标相似 (goalType) —— 权重 10%
  5. 时区/地区相近 —— 权重 5%

匹配算法:
  混元 AI 计算用户画像相似度 → 排序 → 推荐 Top 10
```

#### 4.3.2 好友机制

```
用户流程:
  1. 发现广场 → 浏览推荐学习搭子列表
  2. 查看对方主页 → 学习语言/水平/学习目标/学习时长
  3. 发送搭子邀请 → 附带招呼语（模板+自定义）
  4. 对方收到通知 → 接受/拒绝/忽略
  5. 双向同意 → 成为学习搭子
```

#### 4.3.3 搭子互动

```
搭子功能:
  ├─ 搭子排行榜（本周学习时长/完成课程数）
  ├─ 搭子对话（内置 AI 翻译辅助）
  ├─ 搭子挑战（共同完成学习目标）
  ├─ 搭子纠错（互相批改作业）
  └─ 搭子成就（共同学习里程碑）
```

#### 4.3.4 发现广场

```
发现广场:
  ├─ 推荐搭子（AI 智能匹配 Top 10）
  ├─ 活跃学习者（本周学习时长排行）
  ├─ 同母语学习者（按母语筛选）
  ├─ 同目标语言学习者（按目标语言筛选）
  └─ 搜索（按昵称/母语/目标语言搜索）
```

### 4.4 数据模型

```
新增数据表: StudyBuddy (学习搭子)
  ├─ id, userId, buddyId
  ├─ status (pending/accepted/blocked)
  ├─ matchedBy (ai_recommend/search/invite)
  ├─ matchScore (AI 匹配度评分)
  ├─ createdAt, updatedAt

新增数据表: BuddyInteraction (搭子互动)
  ├─ id, buddyId, type (challenge/correction/chat)
  ├─ content, metadata (JSON)
  ├─ createdAt

新增数据表: BuddyChallenge (搭子挑战)
  ├─ id, buddyId, goalType, targetValue
  ├─ progress (JSON: {userId: progress})
  ├─ startDate, endDate, status
```

### 4.5 依赖关系

```
多身份体系 (student)
  └─→ 学习搭子社交 (AI 匹配 + 好友 + 发现广场)
        └─→ 知识付费生态 (内容创作者社群运营)
```

## 5. 知识付费生态

### 5.1 目标

构建**学习创作双向变现闭环**，让语言教师和内容创作者在 AILOS 平台上获得收益。

### 5.2 核心商业模式

```
┌─────────────────────────────────────────────────────┐
│                AILOS 知识付费生态                      │
├─────────────────────────────────────────────────────┤
│                                                     │
│   创作者 (Creator)                                    │
│     │                                               │
│     ├─→ 创作课程 (AI 辅助)                             │
│     ├─→ 上架销售 (定价/预览/分成)                       │
│     ├─→ 社群运营 (粉丝/学员管理)                        │
│     └─→ 收益提现 (销售分成 + 平台补贴)                   │
│                                                     │
│   学习者 (Student)                                    │
│     │                                               │
│     ├─→ 浏览课程 (分类/搜索/推荐)                       │
│     ├─→ 购买课程 (会员免费/单课付费)                     │
│     ├─→ 学习课程 (视频/音频/习题/互动)                   │
│     └─→ 评价课程 (评分/评论/分享)                       │
│                                                     │
│   平台 (AILOS)                                       │
│     │                                               │
│     ├─→ 内容审核 (AI Language Guard + 人工复审)         │
│     ├─→ 交易抽成 (平台服务费 20-30%)                    │
│     ├─→ 质量管控 (课程评分/投诉处理)                     │
│     └─→ 流量分配 (推荐算法/搜索排名)                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 5.3 功能模块

#### 5.3.1 课程系统

```
课程类型:
  ├─ 录播课程（视频 + 课件 + 习题）
  ├─ 直播课程（实时互动 + 回放）
  ├─ 系列课程（多课时打包）
  ├─ 学习计划（AI 定制学习路径）
  └─ 1v1 辅导（预约制，按小时计费）

课程元数据:
  ├─ 标题、描述、封面图
  ├─ 目标语言、难度等级
  ├─ 课时数、总时长
  ├─ 价格（免费/会员免费/付费）
  ├─ 评分、评论数、购买数
  └─ 标签、分类
```

#### 5.3.2 创作者收益系统

```
收益来源:
  ├─ 课程销售分成（创作者 70-80% / 平台 20-30%）
  ├─ 会员订阅分成（按学习者观看时长分配）
  ├─ 平台激励（优质内容补贴/新人扶持）
  └─ 1v1 辅导收入（创作者 85-90% / 平台 10-15%）

收益管理:
  ├─ 实时销售数据看板
  ├─ 月度结算账单
  ├─ 提现（微信/支付宝/银行卡）
  └─ 税务信息管理
```

#### 5.3.3 内容审核体系

```
审核流程:
  1. AI 自动审核（Language Guard 语种校验 + 敏感词过滤）
  2. 创作者预览（自查）
  3. 平台人工复审（抽查）
  4. 上架发布
  5. 用户举报/评价 → 下架/整改

审核标准:
  ├─ 内容质量（音频/视频清晰度、课程结构合理性）
  ├─ 语种合规（语言卫士校验）
  ├─ 版权合规（禁止盗版/侵权内容）
  └─ 商业合规（禁止虚假宣传/价格欺诈）
```

### 5.5 依赖关系
