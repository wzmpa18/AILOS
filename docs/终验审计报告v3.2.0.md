## 一、验收范围

本次终验覆盖 v3.2.0 社交板块升级的两条主线：

| 模块 | 内容 | 风险等级 |
|------|------|---------|
| 站内优质动态 | SocialTimeline 字段增量 + 优质推荐排序 + 标签体系 + 加精机制 | 🟢 低 |

验收维度：架构合规、合规达标、功能完整性、文件清单完整性。

### 3.1 零直连大模型

| 检查项 | 结果 |

| 资讯域所有 AI 调用走 BrainFacade | ✅ 通过 |
| newsFilterService 无 require 模型 SDK | ✅ 通过 |

**结论**：配额管控生效，默认关闭 AI 零消耗，开启时单条限 1 次。✓

| 检查项 | 结果 |

**结论**：无侵权风险，仅标题+摘要+链接聚合展示。✓

### 4.2 内容审核机制

| 检查项 | 结果 |
|--------|------|
| 抓取内容先过敏感词过滤（规则匹配） | ✅ 通过 |
| 通过过滤内容进入 pending 待审核池 | ✅ 通过 |
| pending 内容前台不可见 | ✅ 通过 |
| 后台人工审核 approve 后方可展示 | ✅ 通过 |
| newsService.getNewsList 仅返回 approved | ✅ 通过 |

**结论**：内容审核机制完整闭环：敏感词过滤 → 待审核池 → 人工审核。✓

### 4.3 违规处理

|--------|------|

| 拉黑来源后停止抓取 + 批量下架 | ✅ 通过 |
| 所有违规处理写入审计日志 | ✅ 通过 |
| 前台举报入口可用 | ✅ 通过 |
| 后台举报处理（dismiss / takedown） | ✅ 通过 |
| 举报命中触发自动下架 | ✅ 通过 |

**结论**：违规处理机制完整：一键下架 + 拉黑来源 + 审计日志。✓
