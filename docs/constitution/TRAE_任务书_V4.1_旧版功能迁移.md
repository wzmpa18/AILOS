### 迁移三条铁律（防交叉污染，违者验收 FAIL）
1. **只迁"玩法外壳与交互"，不迁"内容"**：旧版 `data/languageData.js`、`learningContent.js` 等硬编码题库/词表**一个字都不许复制**。所有内容一律走现版 `aiGateway` + `QuestionBlueprint/CourseBlueprint` 框架 AI 动态生成。
2. **语言零串语**：一切生成内容的语言取自用户语言档案（母语=解释语言，目标语言=学习语言），经 LanguageGuard 校验；严禁写死中文/英文文案在学习内容里（UI 文案走 i18n）。
3. **技术栈对齐现版**：现版 canonical 是 静态 HTML + `src/`(JS/Express/Prisma)。旧版 jsx 只作**功能参照**，逐页重写为现版 HTML 页面 + 后端 API，禁止把 React 工程整体搬进来（避免再造双世界）。

参照旧版：LearnPage(关卡地图) / EnhancedLearningPage / ExamPage / WrongBookPage / ShadowingPage / ReadingPage / GrammarPage / SentenceBankPage / RadioPage / GoalSetting / TrackSelect / PlanGeneration。
