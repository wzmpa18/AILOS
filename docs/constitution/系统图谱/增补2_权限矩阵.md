## 2.2 绝对禁止规则

| 规则 | 违宪等级 |
|------|---------|
| 任何 HTML 页面禁止通过 `fetch()` 直连 `/api/admin/*` 管理后台接口 | 🔴 一级违宪 |
| 任何 HTML 页面禁止通过 `fetch()` 调用未在矩阵中列出的 API | 🟡 二级故障 |
| 任何 HTML 页面禁止直连内部服务路由（非 `/api/*` 前缀） | 🔴 一级违宪 |
| 前端禁止通过 `window.AILOS` 暴露的方法修改语言/等级/配额 | 🟡 二级故障 |

## 2.3 运行时拦截规则（P2 DependencyGuard 实现）

```
请求进入 → DependencyGuard 中间件 → 校验 referer/页面 → 匹配权限矩阵 → 合法？→ 放行
                                                                         → 不合法？→ 9002 DEPEND_VIOLATION
```
