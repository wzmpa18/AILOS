## 任务 1：DependencyGuard 全局运行时中间件（最高优先级）

**Deadline**: Day 1-2 | **关联违宪**: VC-005 | **权重**: 30%

### 1.1 中间件骨架

```
文件: src/server/middleware/dependencyGuard.js
功能:
  - 读取 system-atlas-v3.0.0.json 中的 allowed_calls / forbidden_calls
  - 全局 Express 中间件，拦截所有 /api/* 请求
  - 校验调用链路：referer页面 → 目标路由 → 匹配权限矩阵（增补2）
  - 命中 Forbidden → 返回 9001 DEPEND_VIOLATION + 日志落库
```

### 1.2 注册到 Express

```
文件: src/server/index.js
动作: app.use(dependencyGuard) 在所有路由之前
```

### 1.3 验收标准

- [ ] `curl /api/admin/users` 从非授权页面 → 返回 9001
- [ ] `curl /api/vocabulary` 从词汇页面 → 正常 200
