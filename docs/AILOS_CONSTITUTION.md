```
用户体验 > 产品稳定 > 数据安全 > 架构一致性 > 开发效率
```

### 自主处理范围（无需人工确认，直接执行）

| 类别 | 示例 |
|------|------|
| 文件缺失 | 缺失 Constitution、Playbook、配置文件、测试文件 |

## Chapter 5: ADR 架构变更规则

### 变更触发条件

以下操作必须发起 ADR 审批：

| 操作 | 触发条件 |
|------|---------|
| 修改 Frozen Module | 任何对冻结模块的改动 |
| 新增数据表 | 需明确业务必要性、兼容方案 |
| 修改数据表结构 | 字段增删改、关系变更 |
| API 路由变更 | 路径、方法、中间件栈变更 |
| Prompt 体系变更 | 模板结构、调用策略、PromptBuilder 逻辑 |
| 全局命名变更 | 模块名、函数名、文件名重命名 |
| 架构重构 | 跨模块的代码重组 |

### ADR 文档格式

```
DEC-XXX: 决策标题
- 背景：为什么需要变更
- 决策：变更内容
- 影响范围：涉及的模块、表、接口
- 替代方案：考虑过但未采纳的方案
- 验证方案：如何验证变更正确性
- 回滚方案：出问题如何回滚
```
